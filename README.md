# Pathya Care: live demo

Deployed build of Pathya Care, a condition-aware Indian nutrition web app.
Open it at https://mikhai1-tal.github.io/pathya-care-demo/

All health data stays in your browser (localStorage). Nothing is uploaded.
Pathya gives food guidance, not medical advice. In an emergency call 112.

Nutrient values are IFCT 2017 / INDB-derived and licensed for personal use only.
Do not redistribute them; see DATA_NOTICE.md.
